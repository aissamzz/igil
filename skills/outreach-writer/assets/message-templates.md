# Outreach Message Templates

Tone guidelines and examples per niche and channel.
Claude uses these as reference when generating personalized messages.

---

## Tone Rules (all channels)

- Address the business by name in the first sentence
- Include the demo URL in the second sentence
- Reference 1 specific detail (no website, broken site, their city, their niche)
- End with: `— Aissam, Murus Mare`
- Max 5 sentences
- No: "I came across", "I noticed you", "I hope this finds you", "as a business owner"
- No urgency language ("limited time", "act fast")

---

## WhatsApp

**Tone:** Conversational, brief. Like a message from a business contact, not a cold pitch.

**Dentist (no website):**
```
Hi Dr. [Name] — we built a free demo website for your practice in [City]:
[demo_url]

It's live and ready. If you'd like us to add booking, multilingual support, or SEO — we can handle the full build.

— Aissam, Murus Mare
```

**Aesthetic Clinic:**
```
Hi [Name] — here's a site we put together for [Clinic Name] in [City]:
[demo_url]

Happy to customize it fully and have it live within a week.

— Aissam, Murus Mare
```

**Boutique Hotel:**
```
Hi [Name] — we built a demo for [Hotel Name] that shows what a proper web presence could look like:
[demo_url]

It's live now. We can add a booking engine, room gallery, and SEO if you're interested.

— Aissam, Murus Mare
```

## Email

**Tone:** Slightly more formal. Include a clear subject line.

**Subject:** `Free website demo for [Business Name]`

**Body:**
```
Hi [Name],

We built a demo website for [Business Name]:
[demo_url]

It's live, designed specifically for [niche] businesses in [city], and ready to deploy as-is or customized fully.

If this is something you'd want to move forward with, I'm happy to jump on a quick call.

— Aissam
Murus Mare | murusmare.com
```

## Situation-Specific Variations

**No website at all:**
> "...we noticed you don't have a website yet, so we built one..."

**Dead / broken website:**
> "...since [domain] seems to be down, we put together a replacement..."

**Gmail email (signals unprofessional setup):**
> "...we put together a professional web presence for [Business Name]..."
